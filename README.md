## 二、固定约束（每次记录不变）

| 编号  | 约束             | 数值                     | 说明                           |
| --- | -------------- | ---------------------- | ---------------------------- |
| C1  | 上下文长度          | **≥ 100 万 tokens（1M）** | 只认"实际跑得出 1M"，不认"上游可扩展但不实装"口径 |
| C2  | 出字速度（decode）   | **≥ 50 tokens/秒**      | 对应长文档/长对话的流畅度                |
| C3  | 预填充速度（prefill） | **≥ 1500 tokens/秒**    | 1M 一次性吃 11 分钟以内，门槛最宽松的一条     |

**目标体量（智力门槛）**：10B 激活级 MoE 大模型。**目标模型自动判定规则**：open weights + 进内存总参 ≤250B + 激活 ≤30B 范围内，选 **AA Intelligence Index 最高者**（脚本 `tools/fetch_aa.py` 自动判定；用户可手动指定覆盖）。本期判定结果 = **Qwen3.5-122B-A10B → 已切换为 Qwen3.8-Flash-Next**（AA=56，开放权重最优）。

**⭐ 项目标准（固定，勿改）**：

- **本地运行统一口径：模型权重 Q4 量化 + KV Cache Q8 量化**。本表所有显存/内存判定、硬件方案评估，一律按此口径计算，不因模型官方发布格式（如 GLM 发布即 FP8）而改变。
- **1M 上下文的实现统一按 YaRN 扩展（4 倍）口径判定**：原生 262K 模型 × 4 = 1,048,576。只要模型原生上下文 ≥262K，即视为可扩 1M，扩展方式按官方推荐 RoPE scaling（Qwen 系=静态 YaRN factor 4.0）。扩展本身不作为 C1 的否决理由。
- 模型按**总参数**算内存，不是激活参数（MoE 权重全部要落地）。
- 价格为**人民币**，当时行情价（新卡/二手/魔改分开标注），美元按记录当日汇率换算并标注。

> 换算：Q4 = 0.5 字节/参数；Q8 = 1 字节/元素；FP8（官方发布）也按 1 字节近似，但不作为本表标准口径。

### 2026-08-27（同日补充：GLM-5.3-Flash 部署需求，一级来源实测）

> 来源：官方 HF 仓库 `config.json`（关键字段）+ safetensors 分片实测，非对话推算。详见 `存档-内部工作稿/GLM-5.3-Flash-显存与硬件估算.md`。

**核实到的架构事实（config.json 原文）**：

- `kv_lora_rank = 512`、`q_lora_rank = 1536`、`qk_rope_head_dim = 0`（无旋转 KV）→ **对话里"KV 按 512 压缩维度"的方向被一级来源证实**
- 45 层 = 34 层 linear_attention + 11 层 deepseek_sparse_attention（每 4 层 1 层稀疏注意力）
- `max_position_embeddings = 1,048,576`（原生支持 1M）、`v_head_dim 256`、`qk_head_dim 256`、288 MoE 专家 / 8 激活

**按⭐项目标准（Q4 权重 + Q8 KV）的部署需求（本表判定口径）**：

- 权重：320B 总参 × 0.5 字节/参数 = **≈ 160 GB**（官方当前发布的是 FP8 混合分片 306 GiB，但按项目标准 Q4 计）
- KV@1M：45 层 × 512 latent × 1M × 1 字节 = **≈ 23 GB**
- 合计 1M ≈ **183 GB** → C1 判定：**需 ≥256GB 统一内存档次 或 约 3×80G 显存**；GLM-5.3-Flash 的 M5 Ultra 512G（可用 450GB）、双机集群仍可行，但**纯 256G 以下仍不够**，且理论上限在"能装"档位（S10 之上）

**关于 Q4 量化可用性（已定性原则）**：官方当前无 Q4 权重发布，但社区量化（unsloth 等）对该模型补齐只是时间问题，**本表一律按 Q4/Q8 口径判定，不因"官方暂时没出"而回落 FP8 口径**。

**归档版备注（官方 FP8 口径，供对照）**：官方仓库现有分片合计 306 GiB（FP8+BF16 混合）；按 FP8 部署时 1M 需 ≥768GB 统一内存或 6~8×80G H100/H200。**无论哪种口径，GLM-5.3-Flash 都不便宜**；真正的廉价候选只有 Qwen3.8-Flash-Next 系（88~100GB）。

## 四、判定公式备忘（换算依据）

- 权重体积：Q4 ≈ 0.5 字节/参数；INT8 ≈ 1 字节/参数；BF16 ≈ 2 字节/参数。
- KV Cache：Q8 = 1 字节/元素。FFN 系以"每 4 层 1 层带 KV"结构估 12.29GB/1M；常规 120B 硬头结构按经验 0.265MB/token（1M≈265GB）。
- MoE 内存永远按**总参数**算。
- 出字速度带宽墙 ≈ 内存带宽 ÷ 每 token 需读取的权重+KV 字节数。这是 C2 是否达标的第一判断式，算力其次。
